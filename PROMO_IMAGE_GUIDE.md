# Chrome Web Store Promo Image Guide

## Required Sizes

### Small Promo Tile
- **Dimensions**: 440 x 280 pixels
- **Format**: JPEG or 24-bit PNG (no alpha/transparency)
- **File size**: Recommended under 1MB

### Marquee Promo Tile
- **Dimensions**: 1400 x 560 pixels
- **Format**: JPEG or 24-bit PNG (no alpha/transparency)
- **File size**: Recommended under 2MB

## Design Guidelines

### What to Include

1. **Extension Name**: "SnapQuery" should be prominently displayed
2. **Key Feature**: Show what the extension does (AI assistant, screen reading, etc.)
3. **Visual Appeal**: Clean, professional design
4. **Colors**: Match your brand colors or use the gradient from your extension header

### Recommended Design Elements

- Extension logo/icon
- Short tagline or feature highlight
- Clean, modern design
- High contrast text for readability
- Professional appearance

### What to Avoid

- Small text (hard to read at small sizes)
- Too many elements (cluttered)
- Poor contrast
- Transparent backgrounds (not allowed)

## Suggested Prompts for AI Image Generators

### For Small Promo (440x280):

```
"Create a promotional image for Chrome extension called 'SnapQuery'. 
Dimensions: 440x280 pixels. 
Show a clean, modern design with:
- Extension name 'SnapQuery' prominently displayed
- Tagline: 'AI Assistant that reads your screen'
- Professional gradient background (purple to blue)
- Modern, minimal design
- No text smaller than 20px
- High contrast, readable text"
```

### For Marquee Promo (1400x560):

```
"Create a wide promotional banner for Chrome extension 'SnapQuery'.
Dimensions: 1400x560 pixels.
Wide format design showing:
- Large 'SnapQuery' logo/text on the left
- Feature highlights: 'Reads webpages, PDFs, and images'
- Visual mockup or icon representation
- Professional gradient background (purple to blue)
- Clean, modern, spacious layout
- Suitable for wide banner format"
```

- `chrome-extension/templates/promo/small-promo-template.png` (440x280)
- `chrome-extension/templates/promo/marquee-promo-template.png` (1400x560)

1. Open these in your image editor
2. Design your promotional images
3. Save as PNG files

## File Naming

Once created, name your files:
- `small-promo-tile.png` (440x280)
- `marquee-promo-tile.png` (1400x560)

Or any name you prefer - Chrome Web Store will accept them as long as dimensions are correct.

---

**Note**: These promo images are what users see when browsing the Chrome Web Store, so make them attractive and clear about what your extension does!
