📋 Testing Instructions

Step 1: Open PDF

Click the link below to open your CV PDF:

📄 Open Rabuma's CV PDF

Step 2: Check Console

After opening the PDF:

  1. Press F12 to open Developer Tools
  2. Go to the Console tab
  3. Look for debug messages starting with "PDF Detection" and "PDF content extraction"

Step 3: Test Extension

Once the PDF is loaded:

  1. Open the Chrome AI Assistant extension
  2. Ask: "What is this document about?"
  3. Check if the AI responds with actual CV content

Step 4: Expected Debug Output

You should see console messages like:

Step 5: Troubleshooting

If you don't see the expected output:

  • Make sure the extension is reloaded (go to chrome://extensions/ and click reload)
  • Check that the backend server is running
  • Try refreshing the PDF page
  • Check for any error messages in the console
