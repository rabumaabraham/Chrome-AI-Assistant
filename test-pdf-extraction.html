PDF Testing Instructions

This page helps you test PDF content extraction functionality. Click the PDF links below to test different scenarios.

Test Steps:

  1. Click one of the PDF links below
  2. Wait for the PDF to load in your browser
  3. Open the Chrome AI Assistant extension
  4. Ask questions about the PDF content

Test Questions:

  • "What is this document about?"
  • "Tell me about the person in this CV"
  • "What are the key skills mentioned?"
  • "What is the contact information?"

Expected Results

After clicking a PDF link and asking questions, the AI should:

  • ✅ Detect that you're viewing a PDF document
  • ✅ Extract text content from the PDF
  • ✅ Answer questions based on the actual PDF content
  • ✅ Provide specific information from the document

Troubleshooting

If PDF extraction doesn't work:

  • Make sure the PDF loads completely in the browser
  • Try refreshing the page and asking again
  • Check that the PDF has selectable text (not scanned images)
  • Verify the backend server is running
